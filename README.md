# 定版字幕资源库

Aveya / BOREAC 投放视频的**定版字幕层**集中库。每个版本一对文件：透明字幕层 + 定版预览图，另有该版本的中英文对照文案。

## 直接看

打开 `index.html`（本地双击即可，或访问线上地址）。

- 按编号筛选、浅色/深色切换
- 点任意一张卡片 → 左边是定版预览图，右边是这个版本的中英文文案，可左右对照
- 点预览图 → 全屏查看，`←` `→` 翻版本，`Esc` 退出
- `定版/<编号>.png` 是**透明层**（喂给套字幕脚本的那张）；`定版/<编号>_预览.png` 是看得见的预览

## 目录

```
定版/<编号>.png          透明定版字幕层
定版/<编号>_预览.png      该版本的定版预览图
INDEX.json              机器读：编号 → 路径 + SHA256 + 来源包 + 凭据等级
data.js                 网页数据源
index.html              网页（由 page.html 生成）
page.html               网页模板——改版只动这个
总览.png                 一图看全
build_index.py          唯一生成器（生成器本体不随网页发布使用）
```

## 取一份定版（给脚本/agent 用）

```bash
python build_index.py --find "Q30-1"
```

返回定版绝对路径、SHA256、来源包、凭据等级。拿到路径直接接套字幕脚本：

```bash
python "C:/Users/111/.agents/skills/subtitle-overlay-delivery-YuE/scripts/run_overlay.py" --png "<上一步的路径>" --code "Q30-1"
```

## 凭据分三档，别把推断当事实

| 档位 | 含义 |
|---|---|
| **已证实** | 半成品包里有核对 JSON，且是用户当次确认的定版 |
| **已回填** | 复盘时回填的锁定哈希（文件里带 `Backfilled: true`），**不是用户当次确认** |
| **推断** | 没有任何凭据，按命名规则推断出来的 |

## 编号规则

**版本编号以定版文件名为准，半成品包名只作别名。**

例如 `Q25_用户定版原图.png` 这张就是 **Q25**，不是包名上的 `Q25-3`——包名里的 `-2`/`-3` 是「第几次做」的工序编号，不是这张字幕的版本号。`--find` 主键与别名都认。

## 更新方式

新版定版 PNG 出来后：

```bash
python build_index.py --force      # 重新扫描入库
git add -A && git commit -m "..." && git push
```

推上去之后，线上页面需要 15 秒左右自动刷新（页面每 15 秒拉一次 `data.js`），不用手动刷新。

**注意**：当前扫描范围由 `--days` 决定（默认 10.7 / 10.8）。**新日期批次的包不会自动纳入**，要显式加日期，例如 `--days 10.8 10.9`。

## 完整性

每张定版都锁了 SHA256，且 `库内副本 = 来源包原文件 = INDEX 记录` 三方逐条回验。重建时若源文件变动会报出来。
